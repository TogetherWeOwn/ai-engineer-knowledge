## What

Retrieve incident history and decision rationale alongside current code

A background agent recommended re-enabling async dispatch, which had been disabled after an outage. It lacked the Slack discussion and the postmortem ticket. Without a human in the loop the mistake happens silently, so a context layer must retrieve and reconcile the relevant decisions.
