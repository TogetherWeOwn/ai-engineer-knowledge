# Emit categorical review findings and compute the gate score in code

## What

Emit categorical review findings and compute the gate score in code

LLMs are unreliable at producing numeric scores. Ask the judge for a text label per rubric item, map labels to a score in code, and check judge labels against human labels ('evals for your evals'). Where they disagree, add those cases as hard examples.
