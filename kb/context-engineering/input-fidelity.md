# Validate input completeness before reasoning

## What

Validate input completeness before reasoning

Most failures that looked like reasoning errors were really mishearing: the model never got the right input. They fixed the input side instead (ASR biased by conversation and domain context, a second scoring pass on one-word answers) and did not change the reasoning model.

- **Cost:** Less irrelevant or duplicated input
- **Speed:** Less context assembly and rereading
