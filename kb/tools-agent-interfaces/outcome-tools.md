# Collapse fixed multi-call sequences into task-shaped deterministic tools

## What

Collapse fixed multi-call sequences into task-shaped deterministic tools

Per-step success compounds (99% per step over 100 steps is about 36% end to end), and cost accrues on every step. So every step that needs no judgment moves into a deterministic function or tool: authentication, download plus fetch, verification against the system of record. An SOP skill pins the critical path for whatever remains.

## How to apply (generic)

Test the smallest supported intervention on representative tasks. Compare against a baseline, check correctness and failure cases, and retain a rollback before wider use.

## Expected effect

- **Cost:** Fewer model-owned steps and malformed calls
- **Speed:** Shorter reliable tool chains
- **Quality:** Clearer contracts and evidence
- **Reliability:** Fail-loud errors and recoverable execution
- **Certainty:** Expected directions, not measured local gains; savings across clusters overlap and must not be added.
